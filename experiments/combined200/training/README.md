# 200串仿真数据的新训练版本

用户授权：把新增100串加入训练，并验证、接入可操作的单照片指纹检索。执行者本人，CPU两线程，无GPU和子代理；没有创建无人值守训练队列。原视频、手工球模型、原100串、旧检测模型与旧检索服务保留。

这次沿用已有的ImageNet冻结ResNet18＋CircleNet式圆心、半径、可见性检测头。用原仿真模型初始化，在旧80串＋新80串上继续训练；每批2张旧形态、2张新形态，合计3840张训练图片，48轮×64步、学习率0.00035。特征只缓存在RAM，训练结束释放，未写出大型特征张量。

200串按身份划分：160训练、20开发选权重、10旧测试回归、10新的独立评测。不能把全部200串都训练后再声称未见身份检验。最终选中第24轮，选择只用开发集；不是把训练最后一轮直接交付。

这些是果粒圆心检测指标，不是整串身份准确率。开发数据参与选权重，旧测试曾经查看过，只能称回归。继续训练与增加数据同时发生，不能把改善解释成严格的数据量因果消融。

新版41串受控图库由SYN150–185（30个训练干扰串＋6开发串）和SYN190–194（5个独立库内串）组成，每串72方向。查询是另行生成的新角度、颜色、明暗和画面旋转照片：开发20张；新独立测试40张，来自SYN190–199共10串。SYN195–199不在库中。图库几何来自已知仿真球心，查询圆心由模型检测，身份匹配不使用颜色或真值编号。

旧模型与新模型在同一批新查询、同一图库、同一几何匹配器上比较，分别仅用开发集校准门限；首次查看独立排名之前冻结输入与代码。所有72方向都检查，没有重新引入会漏掉正确视角的全局形状粗筛。向量化假设生成、缓存布局及跳过完全收敛后的重复计算用于提速，已有逐视角及完整41候选等价性检查。

独立结果见 `synthetic_consumer/comparison.json`；每张排名、检测与对应审计均保存。这个受控仿真试验仍依赖已知前景、正交渲染、球形近似；实拍背景、透视、大范围俯仰和成熟阶段变化尚未验证。

## 独立新形态评测已完成

同一图库、同一40张新照片（5串库内20张、5串库外20张），门限在开发集分别选定后冻结：

| 指标 | 旧模型 | 新模型 |
| --- | --- | --- |
| 库内正确接受 | 20/20 | 20/20 |
| 库外正确拒绝 | 20/20 | 20/20 |
| 果粒检测F1 | 0.90869 | 0.91218 |
| 果粒检测召回 | 0.86149 | 0.87198 |
| 果粒检测精确率 | 0.96136 | 0.95627 |
| 中心误差中位数/半径 | 0.05952 | 0.05203 |
| 可核验果粒物理对应 | 387/389 | 393/394 |

新模型多找回10个真值中心，召回与定位改善，精确率略降；不是每项指标都上升。整串身份判定在这批测试上持平。新模型在evaluation_190_02中将一个B029对应到邻近/遮挡的B027（残差约0.53半径），保留为局部误配；不声称每一颗都准确。原测试未用于重新修改权重/门限。

本轮新版查询平均约7.99秒，旧权重配合同一优化匹配器约7.86秒；与前一轮15.9秒的差异主要来自匹配实现提速、图库变化，不是训练让推理变快。

5项测试通过；Chrome实际验证新版查询、库外拒识、随机新照片、上传圈选与指纹下载，无脚本错误。全部新模型40张对应图已查看。17个冻结文件与209个受保护原文件SHA256复核一致。
