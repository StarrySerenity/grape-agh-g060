## 数据与执行方式

原数据只读来源：`E:/grape_growth_workspace_20261013`。旧100串在 `fingerprint_mix_20261014/synthetic`，新增100串在 `synthetic_expansion_200_20261014/synthetic`。每串24视角，共4800张仿真图。数据有200个独立几何身份，不把同串不同方向算成不同身份。

## 实拍协议

最新日期目录为 `E:/grape_data_jurong/20260707/3`，含1至20共20个文件夹。05/06、11/12两对目录的原视频与整套照片SHA256相同，按已有证据合并来源别名：FP3_06→FP3_05，FP3_12→FP3_11。去重后18组视频来源、61张独立拍摄照片，不把重复文件夹宣称为20个独立生物身份。

图库为每组12张既有标注视频帧，共216张；查询为另外拍摄的照片，两侧像素哈希不重叠。**图库和查询都用本轮新权重从原图重新检测圆心**，不使用复制过来的预测节点，更不借用仿真真值圆心。目标串采用已有整串掩膜，尚非自动整串定位。身份匹配只用圆心排布与相对半径，不使用颜色或查询身份。

闭集图库含18组来源；开放集移除FP3_17–20这4组，形成49张库内、12张库外照片。首位候选、通过门限的正确接受、错误接受、无法确认分别统计。检测不足的查询留在总分母里。真实照片只做迁移诊断，不进入训练或门限选择。已有照片曾在其他实验查看过，不能当全新独立真实泛化试验。

## 执行入口

本机使用 `D:/Anaconda/envs/grape1/python.exe`，现有NumPy/SciPy/OpenCV/PyTorch/Torchvision。所有数值进程在导入库前设置MKL sequential与两线程。

```powershell

& 'D:/Anaconda/envs/grape1/python.exe' -B training/train.py
& 'D:/Anaconda/envs/grape1/python.exe' -B experiment.py --phase calibrate
& 'D:/Anaconda/envs/grape1/python.exe' -B experiment.py --phase synthetic --batch 0

```

仿真batch为0至9，每批4张；实拍batch为0至12，每批最多5张，需全部完成再汇总。`calibrate`仅对仿真开发20张选择门限，之后锁定模型、门限、图库和代码SHA，禁止按实拍反馈调参。`results/summary.json`为本轮实际汇总。`reference/`是原实验的只读参考快照，与本轮输出分开；没有用它们替代本轮训练或推理。

本目录目前直接读取本机原数据路径，不宣称是包含4800张训练图的完整跨机器训练包。`source-snapshot.json`记录10614个受保护源文件的SHA256，汇总时再次核对。旧模型、旧实验和原视频/点云/手工编辑均保留。

## 实际结果与核验

48轮已实际完成，选中第24轮。仿真回归库内20/20正确接受、库外20/20无法确认，检测F1为0.91218；物理果粒对应审计393/394，并非每对都正确。

实拍闭集61张：首位候选42/61正确；通过门限的正确接受20张、错误接受2张、无法确认39张。通过门限共22张，接受结果中错误比例为2/22，不能把42次首位正确或20次正确接受当成全部接受数。开放集49张库内：17正确接受、2错误接受、30无法确认；12张库外均无法确认、无误接受。真实域失败原因未做专项消融，不直接归因于门限、遮挡或光照。

5项协议/核验测试通过，独立逐张重算61张的闭集和开放集结果一致。277张真实图像均用本轮权重重新推理。报告见比赛项目 `evidence/combined200-real-20261014/实测报告.md`，原始数值在本目录results。

首次 `experiment.py --phase summarize` 发现上游 `real_consumer_test_20261014/build_report.py` 在21:17快照后于21:18更新。该文件只生成上游说明/CSV，没有被本轮训练、检测或匹配引用。10613个其余受保护文件SHA256一致，冻结模型、门限、图像、几何与计算代码未变。原快照和冻结代码均未改；新增 `summarize_verified.py` 只负责后处理，显式记录报告脚本的前后SHA及时间至 `source-variance.json`，任何其他输入变化仍拒绝汇总。两个针对性测试验证这一行为，原失败记录和更正均保留。
