# 仿真葡萄从100串扩到200串

用户意图：新增100个结构独立的果串，整体轮廓有轻微自然差异，不全部像标准锥形串；球形果粒及已认可的成熟紧凑程度继续保留。原100串和已验证的识别模型不覆盖。

本次是现有数据生成流程的有界扩充。先用原随机分枝文法生成新的骨架/果粒，再以小幅、平滑的长宽和侧肩变化调整整个连接骨架，最终做成熟果粒/枝梗约束求解；不会把同一串改色或换角度算成新身份。6类变化分别为柔和锥形、稍细长、稍短饱满、近柱形、轻微单肩和轻微弯轴；类内参数也随机连续变化。形态数量是项目采样设计，并不声称符合真实品种比例。

在线参考：

- [OIV第二版描述标准](https://www.oiv.int/public/medias/2274/code-2e-edition-finale.pdf)，PDF第138页密度、141页轮廓、142页侧翼；图区分柱形/锥形/漏斗形，侧翼和紧密度独立描述。本项目用小幅变化作工程适配，不给仿真数据冒充正式OIV评分。
- [JKI/VIVC实物记录：Abondant果串](https://commons.wikimedia.org/wiki/File:VIVC24_ABONDANT_Cluster_in_the_field_20085.jpg)，供人工进一步对照的公开记录；本轮使用OIV图示，不复制网上照片入训练集。
- 原骨架文法参考[Xin等2020年研究](https://doi.org/10.1111/ajgw.12444)，项目已有适配实现；本次形态变换未做生物学参数标定。

生成分组在前台执行，每10串核对一次。检查球间穿插、枝梗穿果、挂接、枝梗暴露、数量、唯一结构哈希和轮廓变化，保存24方向图像、前景掩膜、完整模型及球心投影标签。原100串只读，新增为SYN100–199，最终合并清单引用两处文件。

CPU两线程，无GPU/子代理/无人值守任务队列。新增数据不自动改变旧权重、图库或旧评测结论，训练更新需单独评测。

## 已完成与验收

- 共200个独立结构：原SYN000–099保留；新增SYN100–199，每串来自新的随机分枝生成，不是旧串改色或拉伸复制。
- 共4800张288×288图像、4800个前景掩膜，每串24方向。新增100串均有完整球心/半径/可见性标签。
- 新增100串已逐串查看8个方位，共11组核验图，记录在 `visual_review.json`。训练图中的小块灰色缺口是前景遮挡增强，不是三维模型缺果；形态页显示完整模型，统一绿色预览图已排除这种人工遮挡。
- 独立检查200串球面、球间接触、果粒挂接、单根连通骨架及枝梗穿果。初始文法和最终模型均有200个不同结构哈希，4800张图像哈希均不同。受保护的204个原数据/识别模型文件字节一致。
- 新增轮廓长宽比约1.20–1.86；6类各16或17串，类内连续随机变化、类间存在重叠。类别是形态采样方向，不等于正式品种标签。
- 3项形态测试通过；Chrome实际测试200串选择、旋转、类别筛选、全部200缩略图与模型下载，手机宽度无横向溢出，无脚本错误。
