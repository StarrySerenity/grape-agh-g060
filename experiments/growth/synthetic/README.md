# 6串仿真幼果到长大形态的小测试

入口：<http://127.0.0.1:8796/>。

共6串、306粒球形果粒。前3串使用GROW的40天配对窗口，后3串使用YG的14天窗口。每串均由新随机种子的已有分枝文法产生，给定较小果粒半径形成幼果；没有读取前面200串的成熟结构作为这6串的未来答案。生成的完整球面点云用于模拟已有点云和拟合输入，不模拟COLMAP漏面。

幼果几何来自受限随机分枝文法的已有工程适配实现，来源方法见paper_grammar.py。幼果半径采样方向参照已有早期相对尺寸范围，参数并非品种生理标定。全部果粒用球体，JSON保存编号、球心与半径。

预测直接调用未修改的forecast.py，按GROW的10组、YG的8组有效前后期实拍配对，选择训练均值或约束Ridge。阶段未确认的YG07/08不参与。模型估计相对半径和整串轴比；中心整体扩张1.35倍是沿用的展示假设。没有逐粒生物运动或掉粒预测。

输出再进行有界球体接触调整：球心移动限于输出半径的0.8倍，目标间距至少为两球半径和的1.005倍；检查没有低于0.999的互穿球体对。果粒编号、数量、预测球半径保持不变。这是几何外观约束，不是另一个训练出的生长模型。未修改原始预测器、原点云、实拍拟合或手动编辑。

两侧采用同一中心、同一显示尺度、同一旋转和缩放，因此可以直接比较增大程度。可选同粒、显示编号、看背面/侧面/斜俯视、播放起终点插值、下载前后JSON和PLY。两端之间的动画不等于已验证逐日生长曲线；这里比较球形果粒拟合，不展示内部枝梗。

球面点云每粒500点，单个点云约18000～34000点，全部前后点云总计306000点。点云为生成的完整球面，输出不能标作实测成熟点云。

该测试无真实未来答案，能检验流程、同粒一致性、外观和碰撞，不能检验生物生长准确率。现有预测器在真实留一验证中仍有限，GROW总体没有超过均值基线。

固定种子与样例参数：plan.json；前后模型及未调整的原预测：cases/；总结果：results.json；原文件保护：protected_sources.json；测试与浏览器、多角度自查证据：qa/和verification.json。

CPU两线程，无GPU，无新训练，无子代理，无无人批处理队列。仅生成这6个小样例并自查。
